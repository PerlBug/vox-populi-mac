Vox Populi for Mac

Install Vox Populi’s improved AI, balance changes and interface for the Steam Mac version of Civilization V: Brave New World.

Install in a few clicks

  1. Extract the complete macOS ZIP. Keep Vox Populi Mac Installer.app in Documents or Applications.
  2. Launch normal, unmodified Brave New World once, then quit both the game and its launcher.
  3. Open the installer. It finds the default Steam game location. Use Choose Game… if your Steam library is elsewhere.
  4. Select Enhanced User Interface (EUI) if wanted, or leave it unchecked for standard VP. Click Check Compatibility, then Install Beta. Wait for “Vox Populi is installed.”
  5. Launch through Steam and start a new regular Single Player game. No Mods-menu activation is required.

The installer includes its own Python runtimes. No Terminal commands, Python installation, administrator password or developer tools are needed to use it. It does need write access to your Steam game and Civ V user-data folders.

Startup movies and animated publisher logos are skipped automatically. Their files are moved to verified inactive backup names, and the intro-skip option is enabled. Uninstall restores the original movie files and your previous intro preference while keeping other settings changes. Menu loading still takes time.

Requires macOS 11 or later, the reviewed Steam Mac Aspyr 1.4.2 (180925) build, Gods & Kings, Brave New World and the gameplay/civilization DLC. Apple Silicon runs the Intel game under Rosetta. The installer itself runs natively on Apple Silicon or Intel.

Optional Enhanced User Interface

The EUI checkbox installs the bundled VP-compatible EUI and matching compatibility screens. No separate download or Mods-menu activation is needed. The tester reports beta.5's EUI and startup changes working; broader gameplay validation remains limited.

If a beta is already installed, close the game and click Uninstall / Restore first. Then choose your interface and install. Start a new game after switching interfaces. Previous beta saves are archived; cross-interface saves are untested.

For an EUI test, found a city, choose production and research, check unit actions and tooltips, and open city and policy screens. Play a few turns, save, quit, relaunch, reload and finish another turn. Include your EUI selection when reporting problems.

Camera controls

With the map focused, hold W / A / S / D to pan up / left / down / right; release to stop. Arrow keys still work. Both interface choices include these controls.

Plain WASD takes priority over unit shortcuts on those letters; use the unit action buttons instead. Ctrl/Shift/Alt shortcuts, including Ctrl+S to save, are passed through. Text fields keep the game's normal input handling. Camera movement stops on popup, city or diplomacy transitions, mouse clicks and map hiding.

For a quick test, pan in each direction, open a popup while holding a key, release it and return to the map. Check typing WASD in a name field and your normal save shortcut. The input adapter has Lua 5.1 behavior checks; in-game Mac validation is pending.

Why can’t I install it in the MODS folder?

Mac Civ V already has its own native game core, but it cannot load Vox Populi’s Windows DLL from the MODS folder. This port replaces the stock core with a native Mac version of the VP core. It also needs its matching VP database tables during game startup, before ordinary mod activation. Copying files to MODS cannot replace the Mac core or supply that early data load. The installer therefore installs the native core and its matching DLC-style data package together, with backups.

This requirement applies to this VP port. Mods that only change SQL, Lua or assets do not necessarily need a replacement core.

VP remains active in regular games until you uninstall it. It is not a per-save toggle.

Your normal game and saves are preserved

The installer verifies and backs up the original core, cache and saves. Beta games get a separate save folder and Mac save format. Start a new game; stock and Windows VP saves are unsupported.

To return to normal Civ V, close the game and its launcher, reopen this installer and click Uninstall / Restore. Normal saves return. Beta saves and cache are preserved in dated folders; their paths appear under Details. Keep this installer until removal is complete.

Use this installer or a newer version to uninstall. Installers older than beta.5 refuse the startup-owning backup manifest because they cannot restore its movie files. Keep the .vp-mac-disabled movie backups until restoration completes. This installer can also restore earlier betas.

Other mods

Use this beta with official DLC and its optional bundled EUI only. Separate EUI (UI_bc1) or VPUI copies, other VP modpacks and replacement cores conflict. Move separate DLC mods completely outside the game’s DLC folder before installing either interface option. The installer preserves them and supplies its own matching EUI when selected. Additional UI, civilization and gameplay mods are untested; do not activate them for this beta. The installer does not detect every possible third-party modification.

Uninstall before Steam verification, game updates or switching core mods. If a changed game file or backup is detected, retain it and the error message rather than deleting it to force installation.

If the installer or game won’t open

This beta installer is ad hoc signed and is not notarized by Apple. For a downloaded copy you trust, Apple documents the per-app System Settings → Privacy & Security → Open Anyway option after an attempted launch. See Apple’s guide to safely opening apps.

For game or installation problems, click Diagnostics and Copy Details. Share the output, the turn number and what you were doing. Check Compatibility can explain unsupported game builds, missing caches, open game processes and detected EUI conflicts.

Beta scope

The native core’s bridge checks, CP city/turn/save/reload path and full VP first session passed. Long campaigns, all UI screens and later gameplay systems remain unverified. The tested game core is a Debug build. Multiplayer and 43-civilization variants are unsupported. The GUI adds installation controls; it does not expand the game core’s tested scope.

Upstream credits, license notices, release notes and both source snapshots are included inside the app’s resources. This is not an official Aspyr, Firaxis, 2K or upstream Vox Populi release.
